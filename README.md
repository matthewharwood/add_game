# Add Game

## Overview

Add Game is a web-based educational game built to help Dean practice and improve addition skills in a fun, interactive way.

## Features

- Engaging addition challenges tailored for learners
- Simple, intuitive interface
- Tracks progress and encourages improvement
- Responsive design for desktop and mobile

## Technologies Used

- **JavaScript** (92.5%)
- **CSS** (5%)
- **HTML** (2.5%)

## Getting Started

To run the game locally:

1. Clone this repository:
   ```sh
   git clone https://github.com/matthewharwood/add_game.git
   ```
2. Open `index.html` in your browser.
